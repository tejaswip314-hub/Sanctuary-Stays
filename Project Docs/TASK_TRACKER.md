## Task Status Definitions

- **`Pending`**: Task is planned or queued, work has not started.
- **`Started but not finished`**: Agent has actively claimed the task and work is underway.
- **`Blocked`**: Blocked by external dependency, awaiting clarification or prerequisite task.
- **`Finished`**: Implementation verified, tests/build passed, all related specs in `Project Docs/` updated.
